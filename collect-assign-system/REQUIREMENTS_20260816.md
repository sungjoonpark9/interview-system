# 인터뷰 예약 앱 요구사항 정리

기준일: 2026-08-16  
상태: TFT 검토 내용을 반영한 목업 기준

## 1. 기본 원칙

- 앱은 `개인정보 없는 앱`보다 **개인정보 최소화·분리형 앱**으로 설명한다.
- 앱에는 이름·회중·연락처·이메일·건강 정보·면접 결과를 저장하지 않는다.
- 예약코드는 원본 개인정보를 암호화한 문자열이 아니라, 원본과 별도 보관되는 무작위 식별자다.
- 예약코드와 실제 사람의 연결표는 앱 밖의 승인된 환경에서 별도 관리한다.
- 자원봉사자 면접은 **개별 면접**이 원칙이다. 부부·가족 동반 면접 기능은 제공하지 않는다.
- 자원봉사자와 인터뷰어의 정보 수집은 병행하며, 관리자가 배정 단계에서 연결한다.

## 2. 사용자와 권한

### 자원봉사자 — 모바일 중심

- 예약코드로 접속
- 날짜별 오전·오후 단위로 가능한 시간 선택
- 같은 날 오전과 오후 모두 선택 가능
- 최대 7일 범위 선택
- 마감 전 제출 내용 조회·수정
- 확정된 인터뷰 일정 확인
- FAQ 확인
- 정형화된 문의 접수 및 예약코드로 답변 확인

### 인터뷰어 — 모바일 중심

- 인터뷰어 코드로 접속
- 가능한 시간대 복수 선택
- 시간대별 처리 가능 인원 입력
- 제출 내용 조회·수정
- 배정 일정과 처리 인원 확인
- 기존 설문으로 수집한 1차 인터뷰어 가용시간을 관리자가 일괄 반입 가능

### 콜센터 자원봉사자

- FAQ 검색
- 접수된 문의 확인
- 문의 답변 작성
- `접수 → 처리 중 → 답변 완료` 상태 관리
- 전체 자원봉사자 명단·연결표·배정표·예약코드 관리·결과 다운로드 권한 없음
- 개인정보·민감정보가 포함될 가능성에 대비한 비밀 유지 교육 및 서약 여부는 정책으로 결정

### VM 운영 관리자 — PC 중심

- 자원봉사자·인터뷰어 제출 현황 확인
- 기존 인터뷰어 가용시간 자료 반입
- 시간대별 정원 자동 계산 및 필요 시 조정
- 자동 배정 실행 및 수동 조정
- 예약코드 발급·중지·재발급
- 문의 처리 현황과 FAQ 관리
- 운영 결과 CSV 다운로드

### 시스템 관리자

- 계정·권한·환경설정·배포·장애·감사로그·백업·삭제 관리
- 운영 데이터의 일반 업무 열람은 최소화

## 3. 시간 선택·배정 규칙

- 자원봉사자는 개별 시간을 반복 클릭하지 않고 날짜별 `오전`·`오후`를 선택한다.
- 최소 선택 수는 두지 않되 가능한 범위를 최대한 많이 선택하도록 안내한다.
- 인터뷰어는 각 시간대별 처리 가능 인원을 제출한다.
- 관리 정원은 인터뷰어 가용시간과 처리 가능 인원을 기반으로 자동 계산한다.
- 자동 배정을 기본으로 하고 관리자가 수동 조정할 수 있다.
- 초기 자동 배정 목표는 계산 정원의 70%로 두되 운영값으로 조정 가능하게 한다.
- 제출 마감 전에는 동일 코드로 조회·수정하고, 배정 확정 후에는 문의를 통해 변경 요청한다.

## 4. 문의·FAQ 원칙

- 문의 전에 FAQ를 먼저 제시한다.
- 문의 유형은 정형 선택을 우선하고 자유 입력은 최소화한다.
- 이름·회중·전화번호·이메일·건강 정보 등 개인정보·민감정보 입력 금지를 명확히 안내한다.
- 답변은 앱 안에서 예약코드로 확인한다.
- 외부 문자에는 답변 내용 대신 `답변 등록 사실과 앱 주소`만 안내한다.
- 문의 데이터에는 예약코드·유형·내용·상태·답변·시각만 저장한다.
- 보존·삭제 기간은 운영 정책으로 확정한다.

## 5. 현재 목업의 한계

- 브라우저 `localStorage`를 이용하므로 같은 브라우저 안에서만 데이터가 공유된다.
- 실제 인증·중앙 DB·문자 발송·암호화·감사로그·CSV 업로드 검증은 구현하지 않은 화면 검토용 목업이다.
- 실제 개발 전 저장환경, API, 보안, 운영주체와 승인 범위를 별도로 확정해야 한다.

## 6. 아직 정책·시스템 결정이 필요한 항목

- 실제 저장환경과 API 운영 주체
- 예약코드 발급·재발급·회수·만료 규칙
- 자원봉사자 제출 마감과 배정 확정 시점
- 자동 배정 목표 비율의 초기값과 조정 권한
- 문의·답변·접속·변경 기록의 보존 및 삭제 기간
- 개인정보로 보이는 자유 입력을 탐지·가림 처리할 수준
- 답변 완료 문자와 긴급 공지를 발송할 승인 채널 및 담당자
- 기존 1차 인터뷰어 설문 파일의 열 매핑·검증·중복 처리 기준
